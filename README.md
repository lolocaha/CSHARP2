# Задание 1

## Задача 2 (Человек)

### Текст задачи

Создайте сущность Человек, которая описывается:

- Имя: строка
- Рост: целое число

Может возвращать текстовое представление вида "Name, рост: height", где Name и height это переменная с именем и ростом.

Необходимо создать и вывести на экран следующих людей:

- Человек с именем "Клеопатра" и ростом 152
- Человек с именем "Пушкин" и ростом 167
- Человек с именем "Владимир" и ростом 189

### Алгоритм решения

1. Создаётся класс `Человек` с приватными полями `name` (строка) и `height` (целое число).
2. Для каждого поля объявляется публичное свойство `Name` и `Height` с `get` и `set`. В `set` для роста выполняется проверка: рост должен быть больше 0, иначе выбрасывается `ArgumentException`.
3. Конструктор `Человек(string name, int height)` записывает значения через свойства.
4. Метод `ToString()` переопределён и возвращает строку `"{Name}, рост: {Height}"`.
5. В `Main` создаются три объекта и выводятся через `Console.WriteLine`.

## Задача 3 (Имена)

### Текст задачи

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:

- Клеопатра
- Пушкин Александр Сергеевич
- Маяковский Владимир

Обратите внимание, что при выводе на экран не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения

1. Создаётся класс `Имя` с тремя приватными полями: `lastName` (фамилия), `firstName` (личное имя), `middleName` (отчество) и тремя публичными свойствами.
2. Конструктор `Имя(string lastName, string firstName, string middleName)` принимает все три части. Если часть не задана, передаётся `null`.
3. В `ToString()` создаётся список `List<string>`. В него по порядку (фамилия, имя, отчество) добавляются только те части, которые не пусты (проверка `string.IsNullOrWhiteSpace`).
4. Части из списка соединяются через `string.Join(" ", parts)`. Благодаря этому лишних пробелов нет, а незаданные части в строку не попадают.
5. В `Main` создаются три имени из условия и выводятся на экран.

# Задание 3

## Задача 3 (Города)

### Текст задачи

Создайте сущность Город, которая будет представлять собой точку на карте со следующими характеристиками:

- Название города
- Набор путей к следующим городам, где путь представляет собой сочетание Города и стоимости поездки в него.

Кроме того, Город может возвращать текстовое представление, в виде названия города и списка связанных с ним городов (в виде пары: "название:стоимость").

Используя разработанную сущность реализуйте схему, представленную на рисунке 2.

### Алгоритм решения

1. Создаётся класс `Город` с приватным полем `name` и приватным словарём `Dictionary<Город, int> wave`. Ключ словаря это город, в который ведёт путь, значение это стоимость поездки.
2. Конструктор `Город(string name)` задаёт название и создаёт пустой словарь.
3. Метод `AddWave(Город city, int price)` добавляет в словарь путь к другому городу с указанной стоимостью.
4. `ToString()` проходит по словарю циклом `foreach` и формирует строку вида `Название -> Сосед1:цена, Сосед2:цена`. Для соседа выводится только название, а не весь объект, чтобы не возникала бесконечная рекурсия.
5. В `Main` сначала создаются все города схемы (A, B, C, D, E, F), затем для каждой стрелки рисунка 2 вызывается `AddWave`. Если стрелка двусторонняя, вызов делается в обе стороны.

# Задание 5

## Задача 5 (Дроби)

### Текст задачи

Создайте сущность Дробь со следующими особенностями:

- Имеет числитель: целое число
- Имеет знаменатель: целое число
- Дробь может быть создана с указанием числителя и знаменателя
- Может вернуть строковое представление вида "числитель/знаменатель"
- Может выполнять операции сложения, вычитания, умножения и деления с другой Дробью или целым числом. Результатом операции должна быть новая Дробь (таким образом, обе исходные дроби не изменяются)

Затем необходимо выполнить следующие задачи:

1. Создать несколько экземпляров дробей.
2. Написать по одному примеру использования каждого метода.
3. Вывести на экран примеры и результаты их выполнения в формате «1/3 * 2/3 = 2/9»
4. Посчитать f1.sum(f2).div(f3).minus(5)

### Алгоритм решения

1. Создаётся класс `Дробь` с полями числителя и знаменателя и свойствами `Numerator` и `Denominator`. В `set` знаменателя проверяется, что он не равен 0.
2. Конструктор `Дробь(int numerator, int denominator)` принимает числитель и знаменатель.
3. Реализованы методы `Sum`, `Minus`, `Mul`, `Div`. Каждый имеет две перегрузки: для другой `Дробь` и для `int`. Все они возвращают **новую** дробь, исходные не меняются.
4. Формулы для дробей a/b и c/d:
   - сложение: (a·d + c·b) / (b·d)
   - вычитание: (a·d − c·b) / (b·d)
   - умножение: (a·c) / (b·d)
   - деление: (a·d) / (b·c), при c = 0 выбрасывается `DivideByZeroException`
5. Перегрузка с `int` превращает число `n` в дробь `n/1` и вызывает перегрузку для `Дробь`.
6. Так как каждый метод возвращает `Дробь`, работает цепочка `f1.Sum(f2).Div(f3).Minus(5)`.
7. `ToString()` возвращает `"числитель/знаменатель"`.
8. В `Main` создаются дроби `f1 = 1/3`, `f2 = 2/3`, `f3 = 3/4`. Выводятся примеры каждой операции в формате «1/3 * 2/3 = 2/9», затем результат цепочки.
